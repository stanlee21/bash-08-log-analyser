# LogAnalyse — Server Log Analyzer

## Problem Statement

The Rebase website experienced slow performance, and some students reported that the application page had disappeared. Investigating thousands of raw server log entries manually can be time-consuming and difficult.

## Project Goals

- Automate server log analysis using Bash.
- Identify errors and unusual request patterns.
- Summarize important findings in a readable report.
- Help administrators understand potential website issues quickly.

## Tech Stack

- **Language:** Bash Shell Scripting
- **Tools:** Linux command-line utilities
- **Environment:** Linux terminal, VS code
